## Batch089: full reference-checkout integrity

Parent `dcfd71a`. Seal-only checking accepted14 malformed/dirty checkout cases in
the red package batch. Added a read-only guard that checks the checkout root and
exact HEAD, release tag object/type/peeled commit, every tracked blob/mode, clean
index/worktree/untracked status, and both manifest seals. Tracked-byte comparison
also detects edits concealed by assume-unchanged flags. Git optional locks and
fsmonitor are disabled; no index/config/tag changes are made. Private test repos
assert checkout bytes remain unchanged after verification.

Release checks require an annotated tag. Candidate checking requires an explicit
candidate pin and root, exact commit/seals and a clean full tree; it does not
establish a tagged release. Acceptance pin loading and a root-module test both
call the guard, so historical root-only test commands cannot omit this check.
No production runtime dependency on Git is introduced.

```sh

(cd acceptance && GOMAXPROCS=2 go test -p 2 ./...)

```
