Parent 73229e2. Red/green batches cover lossless XML, packaging, document and full acceptance with GOMAXPROCS=2/-p 2. Red shell fails merge/refusal/stale assertions. Green passes 79 native expanded Gherkin cases and batch unit regressions. No individual test commands.

ReplaceBatch accepts explicit target/replacement pairs, preflights all against one source fingerprint, merges disjoint rune deltas on shared leaves and commits exactly once. Duplicate/overlapping selections, stale/foreign targets, invalid text or later unsupported wrappers leave archive and target state unchanged. All-no-op batches keep targets reusable; successful changing targets are consumed.

This is intentionally a Go selected-target atomic API, not extended replace_all's per-match refusal-and-continue policy. extended convenience semantics and result schema remain pending. Unit tests include targets captured from different snapshots with identical source hashes, same-leaf edits, overlap, duplicate, late invalid-character rollback and no-op reuse.
